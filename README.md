STUDENT DASHBOARD

About the Project
A simple web application that displays students’ academic information and course progress.

Features
* Student name, matric number, and department.
* Total courses.
* Completed courses.
* Pending courses.
* in-progess courses.

Technologies Used
* Next.js
* TypeScript
* CSS

Getting Started
Run npm install to install dependencies, then npm run dev to start the development server.

Project Status
Currently under development.
